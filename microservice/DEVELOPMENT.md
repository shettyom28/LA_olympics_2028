# Example Microservice

You can develop this in any language you want, a simple Python example is provided for demonstration purposes.
You can copy this folder multiple times to have multiple micro-services.

## Development

### Requirements

* Python 3.10+
* Visual Studio Code
  * Extension: "Python" (ms-python.python)

### Instructions

To run the project:

* Open this folder in Visual Studio code
* F1 -> "Python: Create Environment" -> "Venv" -> ... "requirements.txt"
* F1 -> "Python: Select Interpreter" -> ".venv"
* "Run and Debug"
